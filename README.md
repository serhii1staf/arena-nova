# Arena Nova — Overgrown Sanctuary

Детализированная оптимизированная 3D-игра. Первая карта — лобби в стиле
заросшего готического собора со светом, льющимся сквозь витражи. Одна кодовая
база работает **в браузере** (как мини-приложение) и **как нативное приложение**
(десктоп через Tauri, с готовностью к iOS/Android). Архитектура заранее готова к
**онлайн-мультиплееру в реальном времени**.

![Лобби](scripts/smoke.png)

> Скриншот выше отрендерен автоматическим smoke-тестом в headless-браузере
> (программный WebGL). На реальной видеокарте картинка чётче и быстрее.

---

## Почему такой стек

Требования были: максимум производительности, лучшие движки, работа и в
браузере, и нативно, и задел под онлайн. Отсюда выбор:

| Слой | Технология | Причина |
| --- | --- | --- |
| Рендеринг | **Three.js** (WebGL2, готов к WebGPU) | Движок №1 для 3D в вебе, огромная экосистема, отличная производительность |
| Язык | **TypeScript** (strict) | Типобезопасность на уровне игрового кода, ноль сюрпризов в рантайме |
| Сборка | **Vite** | Моментальный dev-сервер и оптимальные бандлы |
| Пост-эффекты | **postprocessing** (pmndrs) | Bloom, god rays, ACES-тонмаппинг, SMAA в одном HDR-конвейере |
| Нативная оболочка | **Tauri v2** (ядро на Rust) | Крошечные бинарники, системный WebView, десктоп **и** мобильные из одного кода |
| Сеть | Абстракция транспорта (WebSocket-ready) | Переключение офлайн→онлайн одной строкой |

Весь арт **процедурный** (генерируется в рантайме): нулевые загрузки ассетов,
крошечный бандл (~230 КБ gzip суммарно), бесшовные текстуры.

## Возможности

- Процедурный готический собор: колонны (лате-профиль), стрельчатые арки-рёбра,
  сводчатый потолок, боковые витражи, апсида со светящимся окном, лестница,
  обломки — с инстансингом и слиянием геометрии для минимума draw-call'ов.
- Заросший вид: трава (InstancedMesh с шейдерным покачиванием на ветру), пятна
  мха, свисающие лианы.
- Атмосфера: экспоненциальный туман, парящие частицы пыльцы (кастомный шейдер),
  объёмные световые лучи.
- HDR пост-обработка: **Bloom → ACES ToneMapping → Vignette → SMAA**, плюс
  экранные **god rays** от окна апсиды.
- Плавный контроллер от первого лица: клавиатура + мышь (pointer lock) и
  тач-управление для мобильных (левая зона — движение, правая — обзор, тап —
  прыжок).
- Камера от 1-го и 3-го лица с зумом колёсиком мыши; процедурный
  анимированный low-poly персонаж (ходьба/бег/прыжок/покой), видимый в 3-м лице.
- Персонаж полностью закрыт: капюшон, бандана и тканевые обмотки — кожа нигде не
  видна. Это осознанное решение под мультиплеер: другие игроки видят
  безликую фигуру, а не лицо.
- Плащ — симуляция ткани (инерция от скорости и поворота, гравитация, ветер),
  накрывает плечи и не пересекается с руками.
- Открытый мир (840×840 м): процедурный холмистый террейн с биомами (пляж →
  джунгли → высокогорье → снежные пики), текстурированная почва, пальмы и
  широколистные деревья (гладкие стволы по кривой), кусты, папоротники, цветы,
  поваленные брёвна, руины колонн, валуны, трава, океан, парящая пыльца и
  летающий дракон.
- Высота пропсов и игрока берётся из той же билинейной выборки, что даёт
  поверхность меша, поэтому ничего не левитирует и не тонет в склонах.
- На камни, брёвна и упавшие колонны можно запрыгивать (у пропсов есть «крыша»),
  а стволы и высокие валуны непроходимы.
- Порталы: светящийся шейдерный вихрь в дверном проёме собора и на каменной
  глыбе снаружи; переход между сценами с плавным затемнением (скрывает
  неизбежную паузу на постройку мира).
- Оптимизация мира: чанковый инстансинг растительности — отсечение по пирамиде
  видимости работает по частям, а не «всё или ничего» (≈240k треугольников
  вместо 1.4M).
- Коллизии в открытом мире: пространственный хэш препятствий (деревья, камни,
  глыба) + барьер по линии берега, поэтому по воде не пройти.
- Камера 3-го лица не проваливается в геометрию: луч камеры останавливается
  перед препятствием.
- Разбитые витражи, сквозь которые виден внешний пейзаж (небо + джунгли),
  и объёмные световые лучи, всегда обращённые к камере.
- Процедурный звук (WebAudio, без файлов): эмбиент-ветер, шаги, прыжок,
  приземление.
- **Адаптивное качество**: автоопределение класса устройства (low/medium/high/
  ultra) + динамическое разрешение под целевой FPS.
- Фиксированный шаг симуляции (60 Гц) с интерполяцией рендера — стабильно и
  дружелюбно к сети.
- Сетевой слой с интерполяцией сущностей, готовый к authoritative-серверу.

## Структура проекта

```
arena.nova/
├─ index.html              # загрузочный экран + HUD
├─ src/
│  ├─ main.ts              # точка входа, бутстрап
│  ├─ config.ts            # игровые константы
│  ├─ core/
│  │  ├─ Engine.ts         # рендер-цикл, фикс. шаг, динамич. разрешение
│  │  ├─ SceneManager.ts   # переключение сцен
│  │  ├─ QualityManager.ts # тиры качества + адаптация под FPS
│  │  ├─ AssetManager.ts   # процедурные текстуры + освобождение памяти
│  │  ├─ Input.ts          # клавиатура/мышь/тач
│  │  └─ context.ts        # интерфейсы EngineContext / GameScene
│  ├─ rendering/PostFX.ts  # HDR пост-обработка
│  ├─ world/
│  │  ├─ Cathedral.ts      # сборка собора + коллизии (LAYOUT — общий источник)
│  │  ├─ Vegetation.ts     # трава / мох / лианы
│  │  ├─ Atmosphere.ts     # пылинки + световые лучи
│  │  └─ builders/geometry.ts  # низкоуровневые билдеры геометрии
│  ├─ player/PlayerController.ts
│  ├─ scenes/LobbyScene.ts # первая карта
│  └─ net/                 # NetworkManager + транспорты + типы протокола
├─ src-tauri/              # нативная оболочка (Tauri v2)
└─ scripts/                # gen-icons.mjs (иконки), smoke.mjs (проверка)
```

## Запуск

Нужен Node.js 20+.

```bash
npm install
```

### В браузере (разработка)

```bash
npm run dev
```

Откроется на `http://localhost:5173`. Сервер доступен и по локальной сети —
можно открыть с телефона (адрес `Network:` в консоли) и проверить тач.

### Веб-сборка (продакшн)

```bash
npm run build     # проверка типов + бандл в dist/
npm run preview   # локально отдать dist на http://localhost:4173
```

Содержимое `dist/` — статика, которую можно залить на любой хостинг/CDN
(в том числе встроить как мини-приложение через iframe).

### Нативное приложение (Tauri, десктоп)

Требуется Rust-тулчейн и системные зависимости
(см. <https://tauri.app/start/prerequisites/>). На этой машине всё уже стоит
(проверено `npx tauri info`).

```bash
npm run tauri:dev     # запуск нативного окна с hot-reload фронтенда
npm run tauri:build   # сборка установщиков в src-tauri/target/release/bundle
```

Иконки уже сгенерированы (`scripts/gen-icons.mjs`). Пересоздать:

```bash
node scripts/gen-icons.mjs
```

> **macOS:** для бандла нужен `icons/icon.icns` — сгенерируйте из своего PNG
> командой `npx tauri icon path/to/icon.png`.

### Мобильные (iOS / Android)

Tauri v2 поддерживает мобильные из этой же кодовой базы:

```bash
npm run tauri android init   # затем: npm run tauri android dev
npm run tauri ios init       # затем: npm run tauri ios dev   (только macOS)
```

## Управление

| Действие | Десктоп | Мобильные |
| --- | --- | --- |
| Движение | WASD / стрелки | левая половина экрана (виртуальный стик) |
| Обзор | мышь (после клика) | правая половина экрана |
| Спринт | Shift | стик до упора |
| Прыжок | Space | короткий тап справа |
| Камера 1-е ↔ 3-е лицо | колёсико мыши (зум) | — |
| Выход из захвата мыши | Esc | — |

Переход между картами: войдите в **портал** в дверном проёме собора → окажетесь
в открытом мире у каменной глыбы. Чтобы вернуться, войдите в портал на глыбе.

## Качество и производительность

`QualityManager` определяет тир по GPU/ядрам/памяти и подбирает пресет: предел
`devicePixelRatio`, размер карт теней, вкл/выкл god rays и SMAA, плотность
растительности, число частиц, дальность тумана. В рантайме **динамическое
разрешение** плавно снижает/повышает внутренний рендер-масштаб, удерживая FPS.
Тир и масштаб видны в HUD слева сверху.

Оптимизации: инстансинг повторяющейся геометрии, слияние статической геометрии,
процедурные текстуры (нет сетевых загрузок), HDR-буфер half-float, отсечение по
пирамиде видимости, аккуратное освобождение GPU-ресурсов при смене сцены.

## План мультиплеера (реального времени)

Клиент уже спроектирован под сеть; сервер подключается без переписывания игры.

**Клиент.** `src/net/NetworkManager.ts` работает поверх интерфейса `Transport`.
По умолчанию — `NullTransport` (полностью офлайн). Выход в онлайн:

```ts
// где-нибудь после старта:
const arena = (window as any).arena;               // временно проброшено в main.ts
await arena.engine // ... доступ к сцене/менеджеру
// в LobbyScene создаётся NetworkManager; вызвать:
// await net.connect('wss://your-server.example/game');
// net.join('PlayerName');
```

Протокол (`src/net/types.ts`, без зависимостей от three/DOM — переиспользуется на
сервере):

- Клиент → сервер: `join`, `input` (позиция/поворот + seq + timestamp), `leave`.
- Сервер → клиент: `welcome` (id + серверное время), `snapshot` (список игроков),
  `playerLeft`.

Удалённые игроки рендерятся с **интерполяцией по буферу снапшотов** (задержка
~100 мс) — плавно и устойчиво к джиттеру.

**Рекомендуемый сервер (authoritative).** Так как протокол на TypeScript-типах,
удобнее всего:

- **Colyseus** (Node/TS) — комнаты, стейт-синхронизация, простое масштабирование.
- либо лёгкий **WebSocket-сервер** на Node/Bun/Deno, отдающий `WorldSnapshot`
  ~20 Гц.

**Хостинг.** Fly.io / Railway / любой VPS с поддержкой WebSocket (для WSS —
терминация TLS на прокси). Клиент сам переподключается с экспоненциальной
задержкой.

Дальнейшие шаги для полноценного онлайна: серверная валидация ввода
(anti-cheat), клиентское предсказание + реконсиляция для локального игрока,
дельта-снапшоты и area-of-interest для масштаба.

## Проверка (smoke-тест)

```bash
npm run build
npm run preview          # в отдельном терминале
node scripts/smoke.mjs   # грузит игру в headless-браузере, ловит ошибки,
                         # проверяет что рендер идёт, сохраняет scripts/smoke.png
```

Тест считается пройденным, если движок инициализировался, загрузочный экран
скрылся, и рендер выдаёт draw-call'ы без ошибок в консоли.
